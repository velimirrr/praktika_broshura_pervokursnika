## 4. Описание проекта

**«В помощь первокурснику»** — Telegram-бот и электронная брошюра, предназначенные для быстрой адаптации первокурсников Московского Политеха.

### Основные возможности
- Быстрый доступ к важной информации о вузе;
- Удобная навигация по гайдам;
- Актуальные адреса корпусов и общежитий;
- Полезные лайфхаки и советы от старшекурсников.

**Технологический стек:**
- Язык: Python 3
- Фреймворк: Aiogram 3.x
- Хранение состояний: MemoryStorage
