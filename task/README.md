# 🤖 Телеграм-бот «В помощь первокурснику» — Московский Политех

Бот-помощник для первокурсников Московского Политеха. Содержит полезные гайды, важные контакты, карту кампуса и советы от старшекурсников.

---

## ✨ Возможности бота

- 📚 **Гайды** по учёбе, общежитиям, питанию, Личному кабинету и другим темам
- 📍 **Карта кампуса** и актуальные адреса корпусов и общежитий
- 📞 **Важные контакты** университета
- 💡 **Советы дня** от старшекурсников
- 🌐 **Ссылка на электронную брошюру**

---

## 🚀 Установка и запуск

### 1. Установка зависимостей
pip install -r requirements.txt
### 2. Запуск бота
python main.py
